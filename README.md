# بوابة أمانة المنوفية — حزب مستقبل وطن

صفحة HTML واحدة (Static Site) لاستمارة طلب انضمام تجريبية، مخصصة للعرض على الموبايل والكمبيوتر، وجاهزة للنشر على GitHub وVercel.

> **تنبيه مهم:** هذه نسخة تجريبية (Demo) وليست قناة تسجيل رسمية. لا تُرسل البيانات إلى أي خادم؛ تُحفظ فقط في `localStorage` داخل متصفح المستخدم. لا تستخدمها لجمع بيانات حقيقية أو صور بطاقات رقم قومي قبل ربطها بخادم آمن ومعتمد ومراجعة الالتزامات القانونية وحماية البيانات.

## ماذا تم تحسينه؟

- **موبايل أولًا:** هوامش وأحجام خطوط مرنة، أزرار بمساحة لمس مناسبة، نموذج بعمود واحد على الشاشات الصغيرة، ومنع تكبير iOS التلقائي للحقول.
- **إصلاح الكود الناقص:** كان الكود الأصلي يستدعي دوال غير موجودة (`startRegistration` و`submitForm` و`openAdminLogin`)، ولا يحتوي على سكربت. تمت إضافة المنطق كاملًا.
- **بدون CDN:** تم استبدال Tailwind CDN وFont Awesome وGoogle Fonts بملفات محلية، مع بناء Tailwind مسبقًا. الصفحة تعمل أسرع وتقل احتمالية تعطلها.
- **إدارة حقيقية للطلبات:** بحث، إحصائيات، تغيير حالة الطلب، طباعة، حذف، مسح الكل، وتصدير CSV.
- **طباعة / PDF:** بطاقة طلب قابلة للطباعة بتنسيق مخصص.
- **حماية أساسية:** تنقية كل النصوص قبل العرض لمنع XSS، منع حقن صيغ في ملف CSV، وترويسات أمان في `vercel.json`.
- **خصوصية:** الصور تُعرض فقط ولا تُحفظ؛ لا يتم جمع الرقم القومي؛ يمكن حذف الطلب من الجهاز.
- **إتاحة:** تنقّل بلوحة المفاتيح، تسميات `label` صحيحة، `aria-live`، واحترام `prefers-reduced-motion`.

## التشغيل محليًا

بما أن الموقع ثابت، يمكنك فتح `index.html` مباشرة، لكن يُفضّل تشغيل خادم محلي:

```bash
npx --yes serve .
```

أو:

```bash
python -m http.server 5173
```

ثم افتح: `http://localhost:3000` (مع `serve`) أو `http://localhost:5173`.

### تعديل التصميم

Tailwind مبني مسبقًا في `assets/css/tailwind.css`. بعد أي تعديل في الكلاسات:

```bash
npm install
npm run build:css
```

للتطوير المستمر:

```bash
npm run watch:css
```

## لوحة الإدارة

- زر **إدارة النظام** أعلى الصفحة.
- كلمة المرور الافتراضية: `admin123`
- غيّرها من `CONFIG.adminPassword` داخل `assets/js/app.js`.

> كلمة المرور موجودة في كود الواجهة، لذا فهي **حماية شكلية فقط**. البيانات نفسها محفوظة في متصفح كل مستخدم، ولوحة الإدارة تعرض طلبات هذا المتصفح فقط. لا تعتبرها نظامًا آمنًا متعدد المستخدمين.

## النشر على GitHub

المستودع مُهيّأ مسبقًا بـ `git init` وأول Commit. إذا أردت رفعه لمستودع جديد:

```bash
git remote add origin https://github.com/USERNAME/menoufia-portal.git
git branch -M main
git push -u origin main
```

استبدل `USERNAME` باسم حسابك. إذا كان المستودع موجودًا بالفعل، استخدم رابطه بدلًا من إنشاء واحد جديد.

---

## النشر على Vercel

### الطريقة 1 — من لوحة Vercel (موصى بها)

1. ادخل إلى [vercel.com/new](https://vercel.com/new).
2. اختر **Import Git Repository** ثم مستودع GitHub.
3. الإعدادات المقترحة:
   - **Framework Preset:** Other
   - **Build Command:** `npm run build:css`
   - **Output Directory:** `.`
   - **Install Command:** `npm install`
4. اضغط **Deploy**.

ملف `vercel.json` يحتوي بالفعل على أمر البناء ومجلد الإخراج وترويسات الأمان، لذا غالبًا لن تحتاج لتعديل شيء.

### الطريقة 2 — من سطر الأوامر

```bash
npx --yes vercel
npx --yes vercel --prod
```

سيطلب تسجيل الدخول لأول مرة.

## استبدال الشعار

الشعار الحالي `assets/img/logo.svg` هو **شعار مؤقت** صُمم للمشروع. لاستخدام الشعار الرسمي:

1. ضع ملف الشعار في `assets/img/` (يفضل SVG أو PNG مربع بخلفية شفافة).
2. عدّل مسارات الصور في `index.html` و`assets/js/app.js` (دالة `cardHTML`) إذا كان اسم الملف مختلفًا.
3. إن كان الشعار نصيًا دقيقًا، استخدم نسخة عالية الدقة لضمان وضوحه في الطباعة.

## قبل الاستخدام الرسمي — قائمة مراجعة

- [ ] استبدال الشعار المؤقت بالشعار الرسمي المعتمد.
- [ ] تغيير كلمة مرور الإدارة (مع إدراك أنها ليست حماية حقيقية).
- [ ] إزالة أو تعديل عبارات «نسخة تجريبية» بعد الاعتماد الرسمي.
- [ ] ربط استمارة بخادم آمن (HTTPS) وقاعدة بيانات بصلاحيات مناسبة.
- [ ] تشفير البيانات الحساسة، وتحديد مدة الاحتفاظ، وسياسة واضحة للموافقة.
- [ ] عدم جمع الرقم القومي أو صور البطاقات إلا بوجود أساس قانوني وإجراءات حماية مناسبة.
- [ ] مراجعة الالتزامات القانونية المتعلقة بحماية البيانات الشخصية في مصر.
- [ ] إضافة سياسة خصوصية وشروط استخدام وبيانات تواصل رسمية.
- [ ] إزالة `noindex` من `robots.txt` والـ meta عند الرغبة في ظهور الموقع.
- [ ] اختبار النشر على موبايل حقيقي (iOS/Android) ومراجعة الطباعة.
- [ ] تفعيل المراقبة والنسخ الاحتياطي عند وجود خادم.

## ملاحظات تقنية

- لا توجد أي طلبات شبكة خارجية بعد تحميل الصفحة؛ كل الأصول محلية.
- الطلبات تُخزَّن تحت المفتاح `mfw_requests_v1` في `localStorage`.
- جلسة الإدارة تُخزَّن في `sessionStorage` تحت المفتاح `mfw_admin_session`.
- الصور المختارة تُعرض عبر `URL.createObjectURL` ولا تُحفظ ولا تُحوَّل إلى Base64.
- إذا كان المتصفح يمنع التخزين (وضع خاص/Private)، يعمل الموقع في الذاكرة وتظهر تحذيرات واضحة.
